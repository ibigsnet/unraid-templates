# unraid-templates

Community Applications catalog for **RifleJock / ibigsnet** Unraid plugins.

| App | CA install (`PluginURL`) | Source |
|-----|--------------------------|--------|
| **Storage Guard** | `…/StorageGuard/**stable**/storageguard.plg` | [StorageGuard](https://github.com/ibigsnet/StorageGuard) |
| **Thunderbolt Net** | `…/ThunderboltNet/**stable**/thunderboltnet.plg` | [ThunderboltNet](https://github.com/ibigsnet/ThunderboltNet) |
| **Fabric Routing** | `…/FabricRouting/**stable**/fabricrouting.plg` | [FabricRouting](https://github.com/ibigsnet/FabricRouting) |
| **NBD Export** | `…/NBDExport/**stable**/nbd.plg` | [NBDExport](https://github.com/ibigsnet/NBDExport) |

- This catalog repo: branch **`main` only** (CA reads XMLs here).
- Each plugin **install/update** URL: that project’s **`stable`** branch.
- Lab/manual testing of unreleased code: install from each project’s **`main`** raw `.plg` (not via CA).
